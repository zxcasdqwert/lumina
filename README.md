# Люмина: город фонарей — исправленное поле и тёмная сказочная тема

Волшебная буря погасила фонари Люмины. Хранительница Мира и пять жителей восстанавливают долину и зажигают маяк к Празднику света. Кампания: 20 уровней, десять видимых этапов строительства, пять заказов жителей.

## Запуск

Откройте `lumina/index.html` в современном браузере. Библиотеки и установка не нужны. Сохранение работает, если браузер разрешает localStorage для локальных файлов. Для устойчивого локального сохранения можно открыть папку `lumina` через любой статический HTTP-сервер. SDK при локальном запуске отсутствует: игра автоматически продолжает работу без рекламы и облака.

В папке `lumina` находятся все игровые исходники и ресурсы. `lumina_yandex.zip` содержит только эту папку **без внешней директории**: `index.html` лежит непосредственно в корне архива. После изменений выполните `python build.py` для пересборки архива. Причины исправленных ошибок и архитектура анимаций — в `CHANGES.md`.

## Управление

- Нажмите фигурку, затем соседнюю, либо проведите по фигурке пальцем/мышью. Совпадение из трёх или более собирается; обмен без совпадения возвращается и не тратит ход.
- Все показанные цели нужно выполнить: очки, нужные фигурки, заданное количество клеток тумана. Все отдельные линии одного действия, включая автоматические каскады, увеличивают комбо; очки получают множитель до ×5. Ресурсы за фигурки множителем не умножаются. Ход расходуется на успешный обычный обмен и на каждый применённый бустер.
- Бомбочка убирает область 3×3, включая туман. Свап обменивает любые две разные фигурки. Точный удар собирает одну фигурку. После них срабатывают обычные каскады. Расходуется один ход и один заряд.
- Отменить выбор: повторно нажать активный бустер, «Отмена» или Escape. Выбор первой фигурки можно снять повторным нажатием.
- Подсказка подсвечивает один допустимый обмен. Если обменов нет, поле перемешивается автоматически.
- Победа даёт только светокамни. Повторное прохождение даёт 40% исходной награды (минимум 5) без повторных сюжетных наград. Заказы выполняются за каждые четыре новых уровня, награда забирается кнопкой.
- В городе нажмите «Восстановить» для следующего проекта. Стоимость действительно списывается; для открытия проектов нужны пройденные уровни. Все десять проектов доступны после уровня 20. Полная стоимость — 1170 светокамней; первые победы дают 1970, заказы — ещё 200. Реклама не нужна для завершения.
- Перезапуск начинает уровень заново; использованные заряды не возвращаются. Жизни и ожидание отсутствуют.
- Пауза, звук, справка и язык — кнопками интерфейса. RU/EN определяется через SDK; локально — языком браузера. Язык можно переключить вручную.

## Яндекс Игры

1. Создайте черновик в Консоли Яндекс Игр и загрузите `lumina_yandex.zip`.
2. Укажите HTML5, мобильные и десктопные устройства, русский и английский языки, обе ориентации. Не включайте стики-баннеры: интерфейс не резервирует для них место.
3. Заполните карточку текстами из `publishing/store-texts.md`. Загрузите `publishing/icon.png` (512×512) и подходящую языку `cover_ru.png` / `cover_en.png` (800×470). Обложки — отдельные авторские композиции, не скриншоты. Скриншоты лежат отдельно в `screenshots`.
4. Подключите монетизацию в Консоли. Добровольная реклама в городе даёт +1 каждого бустера **только** по `onRewarded`. Полноэкранная реклама запрашивается при продолжении после каждой третьей победы в сессии, не чаще одного раза в три минуты, без показа во время ходов. В стартовый показ платформы игра не вмешивается.
5. Откройте черновик с debug-панелью; проверьте загрузчик `IT`, Game Ready, события gameplay, guest-профиль, облако, реальные рекламные callbacks и паузы. Затем проведите ручную проверку на физических телефонах.

SDK загружается динамически через актуальный для архива путь `/sdk.js`; скачивать SDK в архив не требуется. `YaGames.init()`, `LoadingAPI.ready()`, `GameplayAPI.start/stop`, `game_api_pause/resume`, `getPlayer/getData/setData`, `showRewardedVideo/showFullscreenAdv` подключены. Игра не вызывает авторизацию. Ошибки SDK/данных/рекламы не блокируют игру. Данные сохраняются локально и через SDK; более новая валидная версия выбирается при старте. Облачные записи объединяются с задержкой 700 мс. Стабильное состояние незавершённого уровня сохраняется после каждого действия; прерывание посреди анимации возвращает последнее сохранённое состояние.
